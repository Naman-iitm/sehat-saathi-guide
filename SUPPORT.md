# Support

Before asking for help:

1. Read the README.
2. Check the documentation.
3. Search existing GitHub Issues.
4. Check GitHub Discussions.
5. Verify that your issue can be reproduced on the latest version.

## Where to Ask

### Bug

Use the Bug Report issue template.

### Feature Request

Use the Feature Request issue template.

### General Questions

Use GitHub Discussions.

### Security Vulnerability

Do not open a public issue.

Follow the instructions in `SECURITY.md`.

## Medical Information

Sehat Saathi is a technology project and does not provide professional medical diagnosis or emergency medical care.

For urgent medical situations, contact an appropriate local emergency or healthcare service.
