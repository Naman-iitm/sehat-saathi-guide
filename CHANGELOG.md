## [0.1.0] - 2026-08-18

### Added

* Multilingual healthcare interface
* Hindi and English language support
* Bengali, Marathi, Bhojpuri, and Maithili localization
* Symptom tracking functionality
* Rule-based symptom triage
* AI health assistant interface
* Healthcare resource discovery
* Nearby healthcare facility discovery
* Government healthcare scheme information
* Medicine browsing and cart functionality
* Responsive mobile-first interface
* Progressive Web App capabilities
* Offline functionality using IndexedDB
* Background synchronization support
* Real-time communication capabilities
* Telemedicine/video consultation functionality
* Authentication and protected application flows
* Healthcare dashboard components
* Vitest testing infrastructure
* Automated GitHub Actions testing
* TypeScript-based application architecture
* Contributor documentation and Code of Conduct

### Improved

* User interface responsiveness
* Mobile usability
* Accessibility
* Application performance
* Offline reliability
* Symptom tracking experience
* Multilingual user experience

### Documentation

* Added project overview and architecture documentation
* Added contribution guidelines
* Added Code of Conduct
* Added project setup instructions
* Added feature documentation

### Security

* Environment-based configuration is recommended for secrets and credentials.
* Security vulnerabilities should be reported privately through the repository's security reporting mechanism.

### Known Limitations

* The application is not a replacement for professional medical diagnosis or treatment.
* Healthcare information should be independently verified before making medical decisions.
* Availability and accuracy of external healthcare services and government-scheme information may change.
* Production deployments should use properly configured authentication, secrets management, database security, HTTPS, and monitoring.

## Versioning

Version numbers follow:

`MAJOR.MINOR.PATCH`

* **MAJOR** — breaking changes
* **MINOR** — backwards-compatible features
* **PATCH** — backwards-compatible bug fixes
